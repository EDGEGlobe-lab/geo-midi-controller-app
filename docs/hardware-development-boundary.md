# PARKWAY Hardware Development Boundary

PARKWAY provides a browser workspace for planning embedded and computer-hardware software projects. It may show code templates, user-written source text, local build instructions, and links to user-owned project assets. It does not discover, read, write, flash, erase, power-cycle, or otherwise control a physical ESP32, microcontroller, motherboard, memory-card reader, removable medium, or attached device.

Any physical programming operation must occur through a user-authorised local companion on a computer to which the user has intentionally attached the device. Before a future companion connection is enabled, PARKWAY must record the device’s owner-approved label, stated purpose, minimum requested access, consent notice version, activation status, and revocation route. The connection begins disabled and cannot collect serial numbers, removable-media contents, location, credentials, private keys, firmware-signing keys, or background telemetry.

The workspace is suitable for drafting code and preparing an authorised local build or flash session. It is not a remote device-management product, automated flashing service, or firmware distribution channel.
