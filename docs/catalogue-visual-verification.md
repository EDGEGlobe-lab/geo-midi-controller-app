# Catalogue Visual Verification

The PARKWAY Catalogue workspace was reviewed at desktop (1280×720) and iPhone 12 Pro-style (390×844) viewports on 2026-08-22.

The desktop layout presents the original-instrumental boundary, unique procedural cartoon covers, current-track guide, waveform playhead, lyric-state disclosure, filter controls, and all twenty compact track cards without visible overflow. The mobile layout collapses the current-track stage, assistant guide, waveform, lyric disclosure, filters, and one-column catalogue list in a readable vertical flow. The player states that vocal lyric timing remains inactive while an instrumental master is selected, avoiding any claim that instrumental files contain singing.

After the verified Night Drive synthetic vocal variant was added, the desktop Catalogue view was rechecked. It exposes separate **Instrumental master** and **Synthetic EDM vocal** controls for the matching track, retains the no-human-source boundary in the player, and keeps the lyric display in the instrumental state until the user explicitly selects the separately labelled variant.
