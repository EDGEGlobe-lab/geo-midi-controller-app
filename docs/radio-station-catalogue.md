The catalogue is a closed, server-validated allow-list. A saved station contains only `ownerUserId`, an allowed `stationId`, and a timestamp. It stores no stream key, listener telemetry, location, radio account, or third-party credentials.

The player requires a browser gesture to begin. Each station shows a project-preview disclosure, not a live broadcaster claim. Favourite/save and unsave actions require authentication and are owner-scoped. Station metadata is static project copy; it must not impersonate external announcers, schedule data, listener counts, or live program feeds.
